# 第五章研究主线与接入边界

## 研究问题

第三章提供强化学习、地图/目标估计与搜索规划。第五章在选定第三章底座上，研究丢包、延迟、连续中断和信息过期如何影响搜索—交接—执行，以及通信和策略如何共同适应该不确定性。

## 建议收敛的贡献结构

**一项核心学习机制：交接关键任务价值驱动的通信与策略协同。** 明确合法信息下的消息价值估计器、调度决策、接收融合和动作生成。消息是否值得发送应关联剩余时间、任务阶段和下游价值；阶段人工固定加分保留为基线。

**一项鲁棒训练机制：针对通信不确定性的显式风险训练。** 定义训练信道集合、风险度量或最坏分布更新及策略优化方式。随机故障增强、域随机化、风险敏感优化与严格 DRO 分别命名。第三章任务奖励与成功语义维持统一，新增通信成本项或约束若采用需单独说明。

**信息合法性与接收记忆是基础。** 时间戳、序号、过期、接收者本地知识和 fallback 必须一致。旧全局目标缓存不能未经交付影响未知执行者。若允许可靠共享目标提示，全部对照同权且缩小结论范围。

## 最小实验矩阵

- 同一底座、同故障训练的普通通信；人工阶段调度；合法历史预测/门控；完整核心方法。
- 关键消融：人工评分与任务价值估计、末状态与历史补偿、普通训练与风险训练；区分重新训练与评价 overlay。
- 理想通信和无研究通道通信作为诊断参考，可靠地图/阶段侧信道另行声明。
- 分离纯通信、纯物理、联合扰动；扫描丢包、延迟、连续中断和预算，增加训练外信道。
- 核心组建议3–5个独立训练种子，固定测试场景，报告种子层区间与配对差异；这不是普遍学位门槛。
- 指标：任务成功、真实交接成功/延迟、消息年龄、接收状态误差、发送/有效交付比特、最差工况与性能—预算折中。
