# CH5 接口设计区

当前没有接入新的鲁棒通信算法。本目录用于后续实施以下接口，具体文件名随已确认方案确定：

1. 消息契约：来源、发送者、接收者、采样/发送/接收时间、序号、置信度、过期与语义截止时间。
2. 信道与预算：丢包、延迟、乱序、连续中断；发送、重传、广播与交付分别计费。
3. 接收者知识：只由合法本地观察与实际收包更新，预测和 fallback 使用同一权限边界。
4. 消息价值与策略：将交接关键消息价值估计、选择、接收融合接入策略训练与实际动作。
5. 鲁棒训练：明确训练通信集合、风险聚合与更新；域随机化、风险敏感和 DRO 按实际算法分别命名。

参考区的旧实现可用于分析与受控移植，不能作为默认运行依赖。第三章任务与地图底座需先冻结；新增通信机制需有相同预算、相同故障训练的基线。
