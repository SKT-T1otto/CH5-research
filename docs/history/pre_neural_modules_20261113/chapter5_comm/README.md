# CH5 接口设计区

当前没有接入新的鲁棒通信算法。本目录用于后续实施以下接口，具体文件名随已确认方案确定：

当前权威设计为 `../docs/CH5_REDESIGN_20261113.md`，文件接入图为 `../docs/CH5_IMPLEMENTATION_MAP_20261113.md`。研究范围为目标、队友状态、地图和控制指令全受限；协调器放在现有Searcher，所有上下行/ACK统一预算。

1. 消息契约：来源、发送者、接收者、采样/发送/接收时间、序号、置信度、过期与语义截止时间。
2. 信道与预算：丢包、延迟、乱序、连续中断；发送、重传、广播与交付分别计费。
3. 接收者知识：只由合法本地观察与实际收包更新，预测和 fallback 使用同一权限边界。
4. 消息价值与策略：通过SMDP通信Actor–Critic学习跨语义选择，覆盖上行—规划—下行的延迟收益；共同任务Actor先冻结，不依赖即时Q差或尚不存在的完整仿真分支。
5. 鲁棒训练：先均值版本，再用连续原任务回报的规范CVaR变体；不把尾部加权PPO或随机故障增强称为严格DRO。

参考区的旧实现可用于分析与受控移植，不能作为默认运行依赖。第三章任务与地图底座需先冻结；新增通信机制需有相同预算、相同故障训练的基线。
