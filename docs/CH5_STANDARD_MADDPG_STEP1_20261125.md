# 第五章标准 MADDPG 第 1 步登记

日期为 2026-11-25。本步登记独立的标准 MADDPG 学习规范、原生任务条件、场景用途和文件字节身份。网络、学习更新、任务闭环和训练性能均未验收，优化器更新与任务回合数为零。几何生成器会运行其原有目标轨迹和真几何可行性检查，这不是策略评价，也不向部署策略开放真障碍或未来轨迹。

## 算法与任务

配置入口为 `configs/chapter5/nominal_maddpg.json`，算法身份为 `ch5.maddpg.single_critic.v1`。四个独立 Actor，各艇一个在线集中式 Critic，另有相应目标网络。观测/动作/集中式 Critic 输入维数为 28/3/124；登记 MSE、单目标 Q、无目标 Q 裁剪、无目标动作平滑、均匀回放。Actor 更新中其他艇动作采用实际回放动作，停用艇按执行门处理。网络规模和 LayerNorm 属于公开实现配置，不是创新声明。学习器尚未实现，配置中任何参数都不是训练结果。

`configs/b2.json` 只提供继承任务、奖励及修复开关；其旧算法标识、输出目录和学习实现不作为新算法入口。已有 `core/algorithms/maddpg.py` 中的双 Critic、最小目标、Huber 和目标裁剪不被登记为标准学习器。

第五章使用原生动力学、0.20/0.15 残差比例、400 步、dt=0.2、gamma=0.95。碰撞、成功、目标运动、奖励及原控制器不变。`resolved.json` 记录构造器完整默认值、传入参数、艇型参数、奖励层次、原配置及实际接口。展开通过禁止 reset 的构造器检查完成，不运行任务。

实际通信路径显式指定 `causal_d2_v1`、`own_history_v1`、`history_rule=native`，不依赖通用实验入口的默认地图模式。所有类别按序列化字节计费，历史地图帧为 1088 bit、原生命令为 224 bit。可靠参考信道仍有排队、传播与至少一步到达延迟。旧配置中的共享地图标签与实际四艇局部导航分开记录；继承共享图仅保留原奖励/诊断用途。部署 Actor、导航及通信选择不能读取全队图、真障碍或未来信息。
