# 第五章实验与可证伪验证计划

日期：2026-11-13。状态：设计方案，未执行新训练或评价。目标是在固定第三章任务/RL/地图底座上，检验异步分型知识与延迟感知通信学习的独立作用。德国论文/TUM/BVPC不在范围内。

**v3补充：核心算法现转为可训练packet编码与几何条件时间解码。网络及损失消融见 [CH5_NEURAL_MODULES_V3_20261113.md](CH5_NEURAL_MODULES_V3_20261113.md)。下文保留协议与预算公平性；实施前须增加标签数据提供器、辅助预训练及第三章context适配，不能把仅训练通信头说成encoder/decoder已由任务回报端到端训练。**

## 共同协议与公平性

- 目标、队友、地图、阶段、上行报告、航点下行和ACK全部经同一受限通信系统。没有免费共享地图、全局Found通知或他艇知识读取。
- 固定协调器由一艘已有Searcher托管；仍为第三章四艇团队，不增加第五艇。协调器只消费自身合法观察和实际收到的消息。协调器单点失联也计入故障试验，不能另开可靠旁路。
- 预共享TDMA时隙只规定本地发送机会。各艇独立选择自己队列的消息；不使用全队实时队列、免费中心调度或无限下行带宽。
- 物理任务、目标运动、障碍、感知权限、动作约束、奖励与任务成功判据固定。通信策略的成本/预算与任务回报分开记录；新增代价项或接口若实施须另行明确版本。
- 各方法使用相同发送机会、包长/头部与序列化规则、队列容量、ACK/重传计费、通信噪声和计算上限。不能只控制包数而让完整法每包承载更多信息。
- 控制自然环境交互总量及额外推演/训练计算。模型参数、推理时延、内存、优化步数分别报告，避免把更多计算误认为消息选择改进。
- 测试场景与故障独立于训练/验证；最终测试不选checkpoint。配对试验使用预生成的物理外生扰动和按边/物理时间索引的信道随机场，而不只设置同一个RNG seed。不同调度造成不同包长、拥塞和交付是方法效果，不能强行把收到的包对齐。

## 分阶段执行

| 阶段 | 目的与产物 | 进入下一阶段条件 |
|---|---|---|
| P0：零训练协议验证 | source-time、唯一证据、合法知识、队列、TDMA、ACK与预算测试；消息来源链/时序追踪；固定场景的实际运行日志 | 以下协议硬约束全通过；任何旁路、重复计数或隐藏免费通信先修复 |
| P1：建立共同任务actor | 选定第三章RL/地图配置；在新本地信息协议下建立共同任务actor；保存源码、配置、场景、预算和checkpoint身份 | 任务actor及信息接口明确，能完成选定任务的基本闭环；没有把旧共享信息actor直接称新协议基线 |
| P2：冻结任务actor，训练通信头 | 固定共同actor，训练基于本地合法知识的on-policy通信头；实际完整轨迹包含上行、协调处理、下行与作用延迟 | 学习信号、动作log-prob、SMDP持续时间和实际任务回报可追溯；不使用一步Q差冒充完整消息价值 |
| P3：主对比与必要消融 | 期望原任务回报版本为主，标准风险版本为配套对照；冻结验证规则并完成多种子独立测试 | 预注册的主要假设得到支持，或按本计划主动收缩表述 |
| P4：可选扩展 | 最后阶段交替更新任务actor和通信头，或扩展额外任务/通用基准 | P0–P3已经闭合；额外计算和非平稳性单列，不依赖它挽救主方法论证 |

复制底座及继承的第三章验证资料不等于完成P0/P1。主线不依赖尚未具备的全系统snapshot/restore，也不要求为消息价值生成器先实现分支模拟。

## P0 必须验证的协议约束

1. **信息隔离。** 故障强制丢弃某消息时，相关新证据不能出现在未收包者的知识、规划器输入、阶段或fallback中。作决策不变性测试时，须固定接收者实际可见的本地传感历史、物理反馈和随机数；不能在改变了其合法本地观测后仍要求动作相同。真实地图、任务真值可用于仿真及事后评价，不作为部署输入。
2. **静态证据幂等。** 同一origin/evidence_id的重发、转发、重复到达不重复增加占据或自由证据。多个独立观测保留各自身份，不能为去重误删独立信息。
3. **目标正负证据的时间一致。** 晚到目标位置对应采样时间；负观测对应当时传感范围和观察条件。窗口内处理与按时间排序的合法证据参考一致；窗口外按明确规则处理并计数，不能静默当作当前证据。
4. **知识类型隔离。** 静态地图不做目标运动外推，目标状态不永久写成静态地图，队友预测不能把当前真值当缺失消息填回。
5. **下行可达性。** 协调器收到上行不代表执行艇立即获知；新航点/阶段必须经过队列并实际下行送达才改变接收艇行为。
6. **ACK真实性。** ACK丢失时发送者不能自动获知成功交付；回执、摘要、重传、广播和转发都计费。
7. **本地发送。** 相同本地信息与随机数下，改变发送者不可见的他艇实时队列不应改变其发送动作。
8. **预算守恒。** 按物理时刻记录全部帧、包头、载荷、重发、ACK和路由开销。超预算处理必须显式，不允许“首个关键包免费超额”。

协议测试失败属于有效性问题，不能靠较高成功率抵消。只通过这些测试也不构成算法优越性证明。

## 方法对照

所有可比较方法使用同一新协议、共同任务actor及动作接口；额外模块训练及交互预算逐项列出。

| 编号 | 方法 | 作用与必须披露的限定 |
|---|---|---|
| U | 新协议下理想可靠/充足预算通信 | 信息充分上界参考；条件不同，不与受限方法作公平带宽排名 |
| N | 所有研究消息关闭，仅本地感知与统一fallback | 完全无跨艇消息诊断；协调器仍是原有Searcher，不能通过中央写状态帮助其他艇 |
| B1 | TDMA机会内固定轮转/公平队列＋末状态 | 最基本同故障基线；所有消息类型均可发送，不能故意不给控制/交接消息机会 |
| B2 | 合法本地阶段/角色启发式调度 | 保留旧VOI思想，证明学习调度是否优于人工任务先验 |
| B3 | 合法模型历史补偿＋启发式调度 | 保留旧固定预测/fallback的工程价值，作为最接近历史原型的合法基线 |
| B4 | CoDe式时效/意图融合适配版 | 公开原算法与本任务接口差异；不把替换部分融合模块称原CoDe完整复现 |
| B5 | VA-MARO式价值加权缺失观测补偿适配版 | 训练真值监督仅允许CTDE；部署只用合法信息；统一原始任务奖励与预算，标明和原MAPPO/通信训练分布的差异 |
| B6 | VIL2C消息价值/低时延机制适配版 | 具体采用的论文版本、等待/反馈假设和可用源码以本轮文献索引核准；不能赠送接收者真值或免费ACK，适配改动必须逐项列出 |
| F | 主贡献A＋B，期望原任务回报训练 | 主方法；冻结共同任务actor，在真实受限协议轨迹上训练通信头 |
| F-Risk | 与F同机制、标准CVaR训练变体 | 检验尾部表现，不列独立首创；不改变任务成功率定义，也不把低回报加权PPO称精确CVaR求解 |

B4–B6按可复现性和近邻程度选择必要外部对照，资源不足时先完成其中两项，论文明确未覆盖者及理由。CATMiP与低带宽Cross-rank用于任务结构/通信假设近邻比较；若只讨论而不运行，不伪造复现结果。参考DHG2Comm可作另一个适配对照，但四艇角色任务无需为了它增加动态拓扑模块。

## 必要消融与机制指标

| 待检验主张 | 受控消融/对照 | 机制指标 | 能推翻或收缩主张的结果 |
|---|---|---|---|
| A避免重复证据导致虚假确信 | 相同唯一原始证据，注入不同重复/转发次数；幂等融合与受控非幂等诊断比较 | 同源证据应用次数、占据校准/误差、过度确信率、错误可达性判断 | 重复注入仍改变幂等版本信念则实现不成立；不改善任务则只保留正确性/估计贡献，不宣称性能增益 |
| A的source-time处理对移动目标有用 | 窗口回放、按到达时间直接更新、丢弃晚到证据；相同窗口/计算预算 | 目标估计误差、负证据冲突、窗口外丢弃比例、真实交接延迟及成功 | 只在回放组使用更多历史或更多计算，不能归因；收益在移动/晚到工况不出现则收缩该贡献 |
| 类型分离优于通用过期衰减 | 几何/目标/队友分型与统一年龄权重 | 地图证据校准、目标误差、队友预测误差、计划失败/重复探索、任务成功 | 只有误差下降无决策收益时分别报告，不能概括为鲁棒任务性能提升 |
| B考虑完整后续作用链 | 延迟感知SMDP头与忽略下行/处理持续时间的同容量头；相同协议自然运行 | 上行送达→协调处理→下行送达→实际导航采用的时间分解，任务回报、失效指令、超时交接比例 | 在加入下行等待后仍只优化上行即时影响、策略不区分后续延迟则核心解释不成立 |
| B跨消息语义分配预算有价值 | 学习选择、B1/B2、固定消息类型配额；同一总比特与机会预算 | 类型分配随本地阶段/剩余时间变化、单位预算任务收益、地图/交接消息饥饿率、端到端关键证据可达率 | 更好性能仅来自更多比特/更大载荷则不能主张调度有效；只学固定先验时按实际结果描述 |
| 学习确实作用于通信决策 | 冻结/随机化通信头，保持共同actor、知识模块及预算 | 发送动作分布、队列选择、实际交付链和任务结果变化 | 随机化后结果不变，须查策略是否未使用通信或模块未激活 |
| 风险训练改善尾部 | F与F-Risk，相同场景、预算、actor、模块容量与训练交互量 | 原任务连续回报均值、低尾经验CVaR、失败/碰撞率、最差预定义工况 | 尾部不改善或只因训练量增加，则不作风险训练有效结论；名义条件性能代价需同时报告 |

移除整个知识模块的主消融应重新训练同接口通信头。只在评价时替换/关闭模块作为压力诊断，标记evaluation overlay，不能与重训消融混算。所有配置都先通过合法信息与预算硬约束；非幂等等错误版本只用于隔离的诊断，不作为部署方案。

## 故障工况与覆盖

采用预注册的一因素扫描加少量有意义的联合压力组，不运行所有参数的全笛卡尔组合。

| 组别 | 控制变量 | 目的 |
|---|---|---|
| G0 | 选定名义物理条件、低故障且预算受限 | 检查机制本身的代价与名义性能 |
| G1 | 仅改变独立/距离相关丢包强度，其余固定 | 丢包敏感性与通信收益 |
| G2 | 仅改变传播/排队/下行延迟，包含异步乱序 | 检验source-time和完整作用链 |
| G3 | 平均丢包相近，改变连续中断长度和恢复节律 | 区分iid dropout和burst的影响 |
| G4 | 仅改变可用比特/时隙预算，保留头部与ACK计费 | 性能—预算曲线，检测是否靠超额发送获益 |
| G5 | 已定义的名义通信下仅增强物理扰动 | 防止把物理变化解释为通信机制 |
| G6 | 通信故障＋物理扰动的少量组合 | 最终联合鲁棒性，不能替代G1–G5 |
| G7 | 训练外的burst/延迟组合、协调器间歇失联 | 泛化与单协调节点依赖；不声称任意未知信道保证 |

所有跨艇通道都参与G1–G7。只故障上行、保留可靠下行或地图不是本方案工况。零通信/整回合断链作为能力边界允许失败，不能假定任务在不可观测时仍必然可解。

## 样本、统计与记录

- 小规模可行性阶段先建议3个独立训练种子；正式核心组建议5个。每个主要测试工况建议200个独立测试场景/故障实例，在不同训练种子间保持配对。这些是预算与精度设计建议，不是已执行数量、通用合格门槛或成功保证。
- 主方法、最强公平基线与关键消融覆盖主要工况；次要模块先在能检验其机制的工况测试，避免无目的扩大训练矩阵。测试规模和最小有意义差值在看最终结果前冻结。
- 训练种子是独立优化重复；同一checkpoint的多个评价seed不是训练重复。汇报逐训练种子结果、均值与区间，使用保留训练种子层级及测试配对结构的统计方法，不能把所有episode当独立训练样本。
- 任务成功率以全部测试回合为分母；交接率同时报告全部任务回合口径及已发现条件口径，不能混用。事件未发生的样本按预先定义的删失/失败规则处理；条件完成时间与成功率同时报告。
- CVaR使用原任务连续回报，报告尾部比例、有效尾部样本数、分位阈值与不确定性。每组200实例在10%尾部仅约20个尾部样本，区间可能较宽；不能因经验尾均值较高就宣称分布鲁棒保证。
- 主终点和少数主要比较预先指定，其他大量工况/消融明确为探索性；报告效应大小与区间，不只挑显著性或最佳种子。

每个run保存源码/父版本身份、完整配置、训练/测试场景ID、物理/故障随机场标识、模型/checkpoint、原始逐回合表、聚合脚本版本与运行完成状态。每回合至少有：原任务回报、任务终止原因、发现/真实交接/任务完成时刻、碰撞字段、实际回合长度、全部发送与交付开销、窗口外/重复证据计数、来源权限审计及各类型消息统计。实测计算时延/内存与协议物理时间分开记录。

## 完成、通过与收缩标准

1. **有效性先行。** P0协议约束必须全部通过；有旁路、免费ACK/下行、超预算或重复证据计数时停止性能论证。修复后使用新版本重新生成受影响结果，不能覆盖历史run。
2. **主贡献A需机制证据。** 先证明预期的重复、晚到、分型效应；如只有协议正确性而无任务收益，保留为方法基础并收缩性能贡献。
3. **主贡献B需公平任务收益。** 预先指定的关键故障组内，完整法相对最强公平基线应显示具有实际意义的配对收益和可解释消息链变化；区间跨零或只在单种子出现时，不称稳定优越。最小有意义差值及名义性能容忍代价在最终测试前冻结。
4. **风险项不强行保留。** 若F-Risk尾部不优或名义代价过大，保留分析并以期望回报版本为主；不把CVaR名义加入贡献清单。
5. **下游作用链若未闭合，缩小消息价值表述。** 不用协调器上行的一步Q差替代闭环证据；必要时只声称真实轨迹学习到的调度改善，而不声称识别了每包的因果价值。
6. **论文对标看证据链而非图表数量。** 所给DHG2Comm有具体算法与多环境/多种子结果，其第五章也缺完整逐模块和物理故障扫描。新章应以明确近邻、实际机制、合法协议、外部对照和独立重复形成扎实程度；不能用参考自身缺口降低本章可复核要求。

全部run完成、日志聚合及失败/未完成状态核实后，才报告实验完成。本文件没有新增实验数值，不把历史汇总移填为新章结果。
